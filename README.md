# Dilema Diario

Vídeos y herramientas del canal de YouTube [Dilema Diario](https://www.youtube.com/@DilemaDiarioTV).

- `videos/` — Shorts publicados (un archivo por episodio).
- `pipeline/` — guion de ejemplo (`episode.json`), voz (`tts.py`), montaje de audio y tiempos (`build.py`), plantilla animada (`comp.html`) y render a MP4 (`render.mjs`).
